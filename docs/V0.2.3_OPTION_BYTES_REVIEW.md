# v0.2.3 Option-Byte Review

This release adds the architecture and safety boundary for STM32H7S3 option bytes.

The implementation deliberately does **not** claim that generic J-Link memory
writes are a correct option-byte programming implementation. RM0477 defines a
dedicated FLASH option-byte control/key/program/launch mechanism, and SEGGER
provides device-specific STM32 option-byte tooling.

Before enabling writes on hardware, validate:

1. exact STM32H7S3 FLASH register offsets and bit definitions from RM0477;
2. unlock key sequence;
3. programming register sequence;
4. launch/reload/reset behavior;
5. readback of current option values;
6. mass-erase semantics;
7. behavior under RDP/HDPL/security configurations;
8. recovery path if the operation changes debug access.

This should be tested on a sacrificial STM32H7S3 board before production use.
